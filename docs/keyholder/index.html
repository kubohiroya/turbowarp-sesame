Sesame keyholder

This page holds your Sesame's device secret, on its own origin. It seals every Bluetooth frame before TurboWarp writes it to the lock, so the secret never reaches a Scratch project or the page that runs it. It contacts no server: pairing and unlocking happen entirely in this browser.

Pair a Sesame

In the sesame app, share an owner or manager key and show its QR code. A guest key will not work: the server keeps half of its secret, so it cannot open a Bluetooth session.

This browser has no passkeys, so a passphrase is used instead.

This browser cannot decode a QR code from the camera. Read the code with any QR reader and paste its text below.
