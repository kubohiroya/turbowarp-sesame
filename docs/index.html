TurboWarp-Sesame

A TurboWarp extension with sandboxed Direct mode and a localhost Relay mode for the Candy House Sesame Web API.

Bluetooth mode

  1. Load dist/turbowarp-sesame.js with Run extension without sandbox enabled, in Chrome or Edge on desktop or Android.
  2. Configure the keyholder URL and a device alias.
  3. Pair by scanning an owner or manager sharing QR code from the sesame app. Guest codes withhold half of the secret and cannot work over Bluetooth.
  4. Run the connect block straight after a click: the browser's device chooser needs a recent user gesture.

The device secret never reaches TurboWarp. It stays in the keyholder page on its own origin, which seals every frame before the extension writes it to the lock.

Relay setup

  1. Start @kubohiroya/keybroker on localhost.
  2. Load dist/turbowarp-sesame.js with Run extension without sandbox enabled. Browsers can deny localhost access from TurboWarp's sandbox iframe.
  3. Configure the Relay endpoint and device alias.
  4. Pair using the one-time code printed by the Relay.

Relay mode keeps provider credentials out of the SB3 file. Credentials written into Direct mode blocks are saved in the project and must not be shared.

Remote commands

Lock, unlock, and toggle requests are disabled in the default build. They can be enabled only by changing the build-time feature flag and rebuilding. After any accepted command, fetch the status again to verify the physical device.

Errors

API blocks return safe empty values when a request fails. Use last Sesame error to inspect the failure.
