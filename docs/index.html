TurboWarp-Sesame

A sandboxed TurboWarp extension for the official Candy House Sesame Web API.

Setup

  1. Obtain an API key, Sesame UUID, and secret key from Candy House.
  2. Load dist/turbowarp-sesame.js as a sandboxed custom extension.
  3. Run the configuration block before status or history blocks.

Credentials written directly in blocks are saved in the SB3 file. Do not share a project that contains real credentials.

Remote commands

Lock, unlock, and toggle requests are disabled in the default build. They can be enabled only by changing the build-time feature flag and rebuilding. After any accepted command, fetch the status again to verify the physical device.

Errors

API blocks return safe empty values when a request fails. Use last Sesame error to inspect the failure.
